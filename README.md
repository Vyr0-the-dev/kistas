# Kıstas

KPSS P3 (ATC) adayları için soru takip ve çalışma planlama uygulaması. Flutter ile geliştirilmiş, koyu temalı Android uygulaması.

## Özellikler

- Soru girişi (ders/konu bazlı), deneme kaydı, hızlı ekleme
- Haftalık/aylık analiz grafikleri, deneme kıyaslaması
- Gemini AI: mentor, hedef önerisi, zayıf konu analizi, haftalık bülten
- Odak zamanlayıcı, çalışma serisi (streak), hatırlatıcılar
- Yerel veritabanı (Isar), yedekleme/dışa aktarma

## Kurulum

Flutter SDK gerekir.

```
flutter pub get
flutter run
```

Gemini AI kullanımı için [Google AI Studio](https://aistudio.google.com/apikey)'dan ücretsiz API anahtarı alın ve uygulama içinde Profil sekmesinden girin. Anahtar kaynak kodda yer almaz, cihazda saklanır.
