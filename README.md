# Kıstas

Mobil odaklı KPSSP3 çalışma ve soru takip uygulaması.

## Notlar
- Flutter SDK gerektirir.
- Çalıştırmak için `flutter pub get` ve `flutter run`.
- Test için `flutter test`.
